# Ward-Beck Systems M522B ST Broadcast Console Equalizer VST/AU Plugin

**Hardware Unit:** Ward-Beck Systems M522B EQ (ST2442 & ST3642 Broadcast Consoles, ca. 1980–1986)  
**Format:** VST3, AU, AAX (C++20 / JUCE 7)  
**Core Shared Engine:** [`wbs_core`](file:///home/anthony/Documents/GitProjects/WBSps.ca/2030.env/vst/core/README.md)

---

## Technical Specifications
- **High-Pass Filter:** $80\text{ Hz}$ active 3-pole ($18\text{ dB/octave}$) Butterworth filter.
- **Mid Bands:** Dual sweepable mids ($150\text{ Hz} - 2.5\text{ kHz}$ and $1.0\text{ kHz} - 14.0\text{ kHz}$) with instant Narrow ($Q = 2.5$) / Wide ($Q = 0.8$) pushbutton switches.
- **Low & High Bands:** $40 - 500\text{ Hz}$ and $2 - 18\text{ kHz}$ with Bell/Shelf toggles.
- **Bi-FET Circuitry:** Texas Instruments TL072/TL074 front-ends on regulated $\pm25\text{V}$ power rails providing $+28\text{ dBu}$ headroom.
